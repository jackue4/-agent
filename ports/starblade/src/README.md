# 星刃：回收协议 · STARBLADE v0.10

Godot 4.7.2 单人 2.5D 科幻动作肉鸽。实体大厅整备，探索连通地牢、击败楼层首领，装备自动收集，撤离带回仓库。长矛与自动飞剑是互斥武器；新角色默认持长矛。

## 启动

- `Launch.cmd`：正式进度，运行 `build/Starblade-v0.10.exe`。
- `LaunchPreview.cmd`：独立试玩进度 `preview_v10.json`。
- `LaunchVFX.cmd`：独立特效实验室，不读取玩家存档。25 个主效果分为五页，可重播、定格、切换。
- 开发环境可在 Godot 打开 `project.godot`，按 F5。

在大厅自由移动，走近英雄终端、工作台、仓库、商店或出击门按 **E** 打开相应界面。英雄终端在大厅北侧，两组设施之间，展示三枚方块角色。工作台选择星铸长矛，或流光／雷隼／断岳三种自动飞剑。只有选择飞剑时才有环绕剑阵。

本次 v0.10 试玩接上 v0.9 保存的局外余额、仓库、英雄与强化，两版使用独立文件。英雄终端内点击“天赋”开始永久培养。

## v0.10 连通地牢

每层九间房在同一场景中由走廊连通，可以自由探索已解锁区域。主路线经过三个战斗房后抵达首领；侧路包含精英房、两间奖励房和一间补给室，也有一条回环路线。偶数层左右镜像，房间组合和空间布局经过可通行检查。地图只显示已探索和相邻发现的房间。

进入未清理的战斗房会封门，清完全部波次后开门并立即喷出自动收集的装备。普通房从第二层开始增加至两波；精英房始终两波。奖励房和补给室每层只能领取一次，回头探索不刷新敌人或奖励。

楼层首领依次轮换炉心看守、棱镜双核、虚空执政，拥有扇射、带缺口环弹、地面震荡、冲锋或追踪区域等不同招式。攻击前有地面预警，半血进入第二阶段。时停会同时冻结首领行动、预警和敌弹。

只有击败本层首领才能启用升降梯。走近按 E，选择继续下一层或带着战利品撤离；继续保留生命、能量、等级、构筑与收获。敌人数量、生命、射击压力和首领强度逐层提高，没有固定的最终层数。详见 [地牢设计说明](docs/dungeon-v0.10.md)。

## 操作

| 动作 | 按键 |
|---|---|
| 移动 | WASD / 方向键 |
| 双充能闪避 | Space / Shift |
| 长矛刺击／蓄力旋扫 | 点按／按住 J 或鼠标左键，松开释放 |
| 投掷／召回 | K 或鼠标右键 |
| 蓄力投掷（需要蓄力穿刺锤） | 按住 K / 右键，松开投射 |
| 冲刺刺击 | 闪避中按攻击 |
| 移动旋扫 | 蓄力达到一档后闪避 |
| 修复剂／过载 | Q / R（30 能量） |
| 英雄主技能 | F，随当前英雄变化，见下表 |
| 英雄副技能 | L，随当前英雄变化，见下表 |
| 设施／通道 | E |
| 祝福三选一 | 点击或 1 / 2 / 3 |
| 构筑与收获 | Tab / B |
| 暂停／关闭弹窗 | Esc |

键盘和鼠标攻击都沿角色当前面向；移动改变朝向，站定后保持最后面向。每招期间角色与枪尖保持同向。飞剑武器自动索敌，不显示或触发长矛 J / K 招式。锤子会改变按键行为，HUD 同步显示连刺、蓄力投掷或爆炸发射等实际操作。

## 三英雄

全部免费，可在大厅终端即时部署；选择自动保存，武器与装备独立保留。三者都有不同的单方块外观、图标、配色和两项主动技能，局内锁定选择。

| 英雄 | F 主技能 | L 副技能 |
|---|---|---|
| 时隙 / CHRONO | 时裂领域：时停 3 秒，40 能量 / 12 秒冷却 | 疾影连击：自动锁定最近可达敌人，0.8 秒至多五段穿梭，35 能量 / 8 秒冷却 |
| 烬刃 / EMBER | 天坠焰击：跃至 6.5 米后砸地，4.8 米范围伤害，40 能量 / 10 秒冷却 | 赤焰回旋：半秒内三重近身旋斩，30 能量 / 9 秒冷却 |
| 磁核 / FLUX | 引力奇点：前方 3 秒聚怪场，持续伤害后塌缩爆破，35 能量 / 11 秒冷却 | 棱镜护卫：40 临时护盾与 4 秒近身反弹，30 能量 / 12 秒冷却 |

时停启动约 0.42 秒的 CRT 同步撕裂、水平压缩和 RGB 错位，随后全屏保持冷灰青荧光扫描线，解冻恢复正常。HUD 只叠很轻的扫描纹理；“减少动态效果”取消入口扭曲并降低错色。再次按处于冷却的技能不会重复触发演出。

时停冻结敌方移动、射击、敌弹寿命和持续伤害计时；玩家、武器、反弹后的友方弹与命中反馈继续。天坠和疾冲都有路径碰撞，疾冲每敌整次最多命中一次。英雄攻击技能携带攻击槽祝福，可搭配长矛或飞剑。棱镜临时盾优先吸收伤害，到期清除，已有普通护盾独立保留。暂停、选卡和构筑菜单保留能力进度，换层及结算清除。普通战斗房清理恢复 15 能量，楼层通关额外恢复 35 能量，蓝色补给继续恢复能量。

## 构筑

开局先选一件锤子强化，再选祝福；第三关再选第二锤。每次升级三选一，战斗暂停。清场积累的升级在掉落自动回收后展开。

- **12 种长矛锤子**：三叉突刺、疾风突刺、锯齿枪尖、延伸突刺、巨大旋扫、迅捷旋扫、炽焰旋扫、连锁穿刺、爆裂发射器、蓄力穿刺、破甲穿刺、残酷穿刺。每局最多两件，冲突组合不会同时出现。
- **16 个核心祝福**：宙斯、波塞冬、雅典娜、阿芙洛狄忒、阿尔忒弥斯、阿瑞斯、狄俄尼索斯、德墨忒尔分别提供攻击与特殊槽祝福。同槽替换，不会叠加八种攻击附魔。
- **8 个衍生祝福**：触电、移动割裂、暴露背刺、虚弱易伤、全局暴击、强化厄运、宿醉减速、十层寒冷爆破。
- **4 个双重祝福**：海上风暴、心碎重击、仁慈终结、恶心诅咒；满足两个神的前置才加入候选。替换前置后暂时失效，构筑面板明确标记。
- 普通／稀有／史诗／英雄品质和重复选择升级会改变实际数值。卡片显示当前数值和替换关系。飞剑拥有独立强化池，也可选攻击槽祝福；不会出现长矛锤子和无效的特殊槽祝福。

八种状态均有真实战斗效果：雷击连锁、击退、弹道反弹、虚弱减伤、暴击、延迟厄运、宿醉叠层、寒冷减速。精英和首领拥有独立护甲层，破甲投掷对护甲生效。

## 清场、掉落与成长

最后一个敌人倒下，当帧喷出装备与补给。随机初速度、重力、旋转、碰撞反弹和两次落地弹跳形成抛撒；落地亮起品质光柱，随后自动飞向角色，通常约两秒完成。无背包容量、无拾取按钮。清场动画与掉落并行，结算数值立即显示，Enter 可返回大厅。

白／绿／蓝／紫／金对应普通到传说。房间内的箱罐可打碎，概率掉装备或红／蓝即时补给；即时补给仍需靠近吸取，生命或能量已满时不浪费。

首领房的升降梯按 E 继续下一层或撤离。继续保留生命、构筑和全部携行收益；撤离将装备存入仓库，并获得信用点。战败遗失本局物资、付费飞剑和出战装备，永久仓库保留。免费长矛和流光不会从解锁列表中丢失。下一局可到相应楼层回收上一次遗失物资。

在英雄终端进入天赋页：每位英雄有三条相连的成长路线，共九个永久节点。信用点共用，节点各自保存，切换英雄不会共享天赋。每条路线依次花费 180 / 360 / 650 信用点，逐步点亮基础属性和专属能力；天赋不会因战败丢失。

- 时隙：生命、移速、伤害与暴击，以及连击索敌距离、技能效率和更长的时停。
- 烬刃：更强、更大范围的天坠焰击和更大的回旋，以及基础属性和技能效率。
- 磁核：更厚的棱镜护盾、更宽的引力场与更高的引力伤害，以及基础属性和技能效率。

商店新增九种装备：精良／稀有／史诗各一套剑芯、护甲、回路。购入后进入仓库，装配后出击生效；价格高于回收价，传说品质仍由探索获取。出售普通物资、修复剂补给和核心委托保留。工作台负责选择主武器；旧存档已购买的反应堆、装甲收益继续生效。

所有设施与局内面板加入开合动画，天赋解锁播放连线充能和节点点亮。“减少动态效果”提供淡入淡出版本。保存使用临时文件、备份与替换，失败不重复扣款或结算。正式存档：`%APPDATA%\StarbladeExtraction\profile.json`。

## v0.9 卡牌与打击表现

新增内置出图工具制作的十张元素主题插画，覆盖八神祝福、锻造、双重祝福，并按主题用于飞剑强化。资源与完整提示词保存在 `assets/cards/`。选卡采用大幅插画、品质边缘辉光和悬停抬升，技能文本独立排版。

长矛三段射程扩至 3.7 / 3.95 / 4.25 米，近身判定消除脚下空隙；飞剑索敌基础范围增加 12%。天坠落地触发方块地砖环波、热熔裂纹、立体碎块和局部屏幕折射；击杀增加装甲碎裂、短暂停顿和分级屏幕反馈。

## 特效与验证

新增可复用的 Godot CPU 粒子、空间着色器、分层弧刃、亮芯、地面符文、碎晶与余辉，适配当前 Compatibility 渲染器。独立图库和实际战斗共用 `scripts/combat_vfx.gd`，暂停同时冻结粒子、着色器进度和寿命，换关清理，有并发上限。

v0.6 加入金属边缘高光、刻线面板、电路地砖与轻量画面调色。大技能与清场触发逐格隆起的地面冲击波；时停使用透明钟面、空间裂壳和释放碎晶，疾影使用细长弧刃与像素双眼方块残影。清场增加暖色厚薄方块向外上方炸开的效果。新屏幕飘字区分普通、暴击、护甲、寒冷和持续伤害，同一帧多段命中错位弹出，敌人死亡后仍完整消散。
