# 实时验收与轻量编辑

编辑窗口里的验收现在使用独立 Godot Web 游戏实例。游戏自己连续渲染，移动和断言在该实例内实际执行；服务器接收检查结果和实测帧时统计。截图仅用于保留证据，不再驱动画面播放。编辑工地、验收实例与玩家试玩实例相互独立。

## 执行与结果

- 可见编辑页面通过短租约注册。只有对应客户端、制作轮次、命令、运行会话、构建和源码版本完全一致的回执才生效。
- 每次规则验收载入新的游戏实例，避免上一轮操作污染初始状态；连续试玩操作使用同一实例。
- 首帧确认读取游戏包内的真实构建标识。没有执行断言、错误、取消、页面离开或客户端失联都不能标为通过。
- 页面关闭后下一次任务可明确使用原生回退；已开始的浏览器验收中断不会静默换成原生成功。
- 自动验收结束保留结果。手动试玩切换到玩家实例，停止验收输入，玩家操作不会被自动控制覆盖。
- 场景小人的工作状态来自实际文件、模块及保存/检查事件。敲代码动作是状态表达，不能生成虚假的进度或验收结果。

## 玩家参与编辑

首版编辑支持已进入规范关卡数据的 3D 实体：选中、拖动水平位置、坐标微调、撤销，以及自由查看镜头。运行时临时生成的角色和特效不属于首版编辑对象。

拖动先改变预览，松开后保存。服务器校验关卡修订、对象身份和位置范围，冲突或保存失败还原到有效场景。重复发送同一编辑请求不会重复增加版本。保存改变真实关卡数据和碰撞位置，同时使旧版本的验收结果失效。

制作或保存占用场景时可以查看镜头，但暂时锁定实体移动。进入试玩前编译并载入包含编辑坐标的新包；编译失败留在编辑模式，保留调整，不把旧游戏当成编辑后的结果。

## 验证

自动回归覆盖回执身份、租约、取消、错误和空断言、构建一致性、编辑冲突、持久化、撤销和失败恢复。真实浏览器 Demo 的截图和验证记录保存在 `artifacts/runtime-editor-v2/`；具体实测结果在完成后附于此文。
